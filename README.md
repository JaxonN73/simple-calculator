# A simple UI/UX Calculator

A responsive calculator app built using Pything and Tkinter, focused on clean layout and a smooth UX.

##Features
- Grid layout
- Error handling
- Responsive resizing

## How to run
1. Clone the repo
2. Run 'calculator.py' in Python 3
